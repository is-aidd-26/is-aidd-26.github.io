## Суть проекта

Все студенты делают **мессенджер либо чат техподдержки**.

Каждый проект студента должен иметь одную ключевую продуктовую идею и 1-2 дополнительных фичи.

## Варианты проектов

Студент может выбрать один из вариантов от преподавателей либо придумать свой вариант.

Варианты от преподавателей:

1. Корпоративный мессенджер для SMB для внутренней переписки сотрудников
2. Чат техподдержки для сайта
3. Мессенджер для университетов — связь студентов с преподавателем
4. Чат-рулетка — случайный собеседник в чате
5. Безопасный мессенджер для фанатов криптографии и анонимности

## Дополнительные фичи

Правила:

- Дополнительные фичи должны подходить под ключевую идею продукта.
- Дополнительной считается фича, которой нет в примерах от преподавателей.
- Студент может выбрать дополнительные фичи от преподавателей либо придумать свои.

Варианты от преподавателей:

1. Групповые чаты
2. Избранное (чат с самим собой)
3. Поддержка emoji
4. Отображение статуса (онлайн/отошёл/оффлайн)
5. Несколько реакций на сообщения
6. Отложенные сообщения
7. Автоматическое удаление сообщений после прочтения для безопасности
