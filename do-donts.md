## Do

Необходимо:

1. Самостоятельно верифицировать весь результат работы ИИ по всем требованиям лабораторной.
2. Проверять, что код собирается без предупреждений и ошибок, включая тесты.
3. Следовать правилам [семантического нейминга комитов](https://gist.github.com/joshbuchea/6f47e86d2510bce28f8e7f42ae84c716).

## Don't

Нельзя:

1. Вносить изменения в различные файлы конфигурации без апрува преподавателей.
2. Отключать линтеры, предопределённые преподавателем.
3. В коде ловить и просто игнорировать исключение, которое не может быть обработано.
4. Оставлять код, который не нужен\не используется.
5. Оставлять множество комментариев в очевидных местах, например:

    ```cs
    // Отдельный класс Program вместо top-level инструкций.
    static class Program
    {
        // Main - точка входа в программу.
        static void Main(string[] args) 
        {
            // Вывод приветствия в консоль.
            Console.WriteLine("Hello, world!");
        }
    }
    ```
